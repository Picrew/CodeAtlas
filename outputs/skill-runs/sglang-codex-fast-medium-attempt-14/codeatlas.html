How To Read This (Junior-Friendly)

  • Arrow direction: source -> target means source module relies on, calls, or flows into target.
  • Color meaning: each edge color is a relation type (imports / depends_on / calls / runtime_flow).
  • Impact hint: if many arrows point to one module, changing it can affect more files.
  • Learning path: start from Entrypoints, then follow arrows in the relationship graph.
